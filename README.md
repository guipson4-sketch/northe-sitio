# NORTHE — sitio web

Sitio de una sola página de **NORTHE**, consultora de marca y marketing digital en Piura, Perú. Posiciona a NORTHE como especialista del norte del Perú por rubros (gastronomía, salud y estética, inmobiliario y construcción, campañas institucionales) y busca generar solicitudes de auditoría de marca.

Dominio: https://northeconsultora.com

## Contenido

| Archivo | Descripción |
|---|---|
| `index.html` | Página completa (HTML + CSS + JS integrados), modo claro/oscuro, JSON-LD `ProfessionalService` |
| `northe-logo.svg` | Logo |
| `og-northe.png` | Imagen para compartir en redes (Open Graph) |
| `robots.txt` / `sitemap.xml` | SEO básico |
| `CNAME` | Dominio personalizado para GitHub Pages |
